# Rule: Cloud server for cohort services

I'd like us to rent a small cloud server (about £11 a month) to host the room booking system at booking.newspeak.house and our cohort site at 2026.newspeak.house.

## Why

We need to host the cohort site, newsletter, booking system and other stuff. Booking system is currently on my own home server, not an ideal place for it. 😅
Folks who build experiments can also host their projects here for public sharing.
It needs to be accessible to all members of the cohort & billing needs to be auditable.

## Proposed

DigitalOcean, London data centre: 1 CPU, 2 GB memory, 50 GB disk, weekly backups. $14.40/month. Can be scaled up/down based on need.
Data stays in the UK. Billed monthly, cancel any time. Most value for money option without an annual lock-in.
